# بندهای نمونه‌ی تأییدشده

این فایل منبع اصلی بخش حقوقی دستیار است. هر بند را خودتان یا وکیلتان بنویسید و تأیید کنید. دستیار هیچ متنی را به‌جای بند تأییدشده نمی‌نویسد و اگر بندی اینجا نباشد، فقط پیشنهاد می‌دهد و با برچسب «نیازمند تأیید وکیل» علامت می‌زند.

برای هر بند وضعیت تأیید را بنویسید: چه کسی، چه تاریخی، و برای چه نوع قراردادی (حقیقی یا حقوقی).
