## راهنمای ستون‌ها

- **بخش:** فرانت‌اند، بک‌اند، دواپس، طراحی، موبایل و غیره.
- **مجری:** من، عضو تیم، پیمانکار فرعی یا نامشخص. برای بخش‌های بیرون از تخصص حتماً پر شود.
- **راه‌حل انتخاب‌شده / گزینه‌های ردشده:** مثلاً «سرویس آماده؛ ردشده: ساخت سفارشی چون زمان‌بر است».
- **ساعت (محتمل):** محتمل‌ترین زمان. اگر خواستید دو ستون اختیاری «خوش‌بینانه» و «بدبینانه» هم اضافه کنید تا بافر ریسک دقیق‌تر تنظیم شود.
- **اطمینان:** بالا، متوسط یا پایین.
