# بخش «پروپوزال» در settings.md

تنظیمات شخصی در یک فایل است: `settings.md` در پوشه‌ی کاری (بخش ۱ `assets/shared-contract.md`). فایل سه بخش دارد: «مشترک»، «پروپوزال» و «برآورد». بخش مشترک (تخصص‌ها، نرخ ساعتی، زمان آزاد، حاشیه‌ی سود، اعتبار پروپوزال، مهلت تأیید، آستانه‌ی تعدیل قیمت، دوره‌ی رفع باگ رایگان) در `assets/shared-contract.md` تعریف شده است. بخش برآورد را دستیار برآورد اضافه می‌کند.

این بخش را دستیار اولین بار زیر `## پروپوزال` اضافه می‌کند. هر چیزی که خالی بماند با پیش‌فرض Skill پر می‌شود. اگر تیم یا شرکت ساخته شد، فقط مقدارها عوض می‌شوند؛ خود Skill تغییر نمی‌کند.

