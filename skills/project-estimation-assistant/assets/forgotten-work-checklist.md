# چک‌لیست کارهایی که در برآورد فراموش می‌شوند

هر مورد این فهرست در هر برآورد کامل یا ردیف (کار با O/M/P) می‌گیرد یا یک دلیل «لازم نیست، چون…». اسکریپت هر دو را زیر کلید `checklist` فایل JSON چک می‌کند. دلیلش این است که این‌ها همان کارهایی‌اند که برآوردها را بی‌صدا کوتاه نشان می‌دهند؛ قاعده‌ی «یا ردیف یا دلیل» حذف بی‌صدا را غیرممکن می‌کند.

## کارهای قابل‌تحویل: ردیف جدا

| کلید | مورد | چه چیزی در ردیف می‌آید |
|---|---|---|
| `testing` | تست | تست در سطحی که با کارفرما توافق می‌شود؛ برای هر milestone که کد دارد. |
| `deploy` | راه‌اندازی محیط و deploy | دامنه، SSL، میزبانی داخلی، CI و deploy. اگر سرور داخلی است، گرفتن image و پکیج از mirror داخلی. |
| `foreign_deps` | جایگزینی وابستگی‌های خارجی زمان اجرا | میزبانی فونت و اسکریپت روی سرور پروژه، جایگزین داخلی نقشه، captcha، آنالیتیکس و گزارش خطا. |
| `integrations` | راه‌اندازی یکپارچگی‌ها | درگاه پرداخت از sandbox تا production، پنل پیامک، نقشه، کمک به کارهای اداری اینماد. |
| `security` | امنیت پایه | احراز هویت، بررسی موارد رایج OWASP، نسخه‌ی پشتیبان. |
| `docs` | مستندات | در حدی که توافق می‌شود: راهنمای کاربر یا ادمین، README فنی. |
| `handover` | تحویل | انتقال repo، دسترسی‌ها، حساب‌هایی که به نام کارفرما ساخته می‌شوند، جلسه‌ی تحویل. |
| `data_migration` | انتقال داده یا ورود محتوا | فقط اگر در محدوده است. |
| `warranty` | دوره‌ی رفع باگ رایگان | دوره‌ی بخش مشترک `settings.md` (پیش‌فرض ۳۰ روز). ساعت می‌برد، پس باید در قیمت باشد. |
| `client_revisions` | دورهای اصلاح کارفرما | برای هر milestone تعداد مشخصی دور (پیش‌فرض ۲) با ساعت. همین تعداد در پروپوزال نوشته می‌شود و دور بیشتر درخواست تغییر است. |

کار اتصال بین نقش‌ها (مثلاً توافق روی قرارداد API بین فرانت و بک، یا تحویل طراحی به برنامه‌نویس) هم ردیف جدا می‌گیرد. این‌ها کار قابل‌تحویل‌اند، نه سربار.

## سربار پیوسته: درصد، نه ردیف

- **مدیریت پروژه، جلسه‌ها و ارتباط با کارفرما:** ۱۰٪ ساعت پایه (قابل تغییر در `settings.md`). اسکریپت حسابش می‌کند و با نرخ کاربر قیمت می‌خورد.
- **هماهنگی تیم:** وقتی بیش از یک نفر هم‌زمان کار می‌کند، ۱ ساعت در هفته برای هر کانال ارتباطی (n(n−1)/2). اسکریپت از روی زمان‌بندی حسابش می‌کند.

## چیزی که عمداً ردیف نمی‌گیرد

- **دوباره‌کاری ناشی از باگ و اشتباه:** کار بافر است. ردیف جدا ریسک را دو بار حساب می‌کند.
- **دوباره‌کاری ناشی از تغییر نظر کارفرما:** درخواست تغییر است و قیمت جدا دارد.
